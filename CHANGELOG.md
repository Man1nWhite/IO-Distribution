# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[SemVer](https://semver.org/lang/ru/). Сначала поведение макроса
(`Module1.bas`), затем проверки и инфраструктура.

## [Не выпущено]

### Добавлено

- `D21` «Шкафов»: после успешного расчёта макрос пишет туда фактическое число
  шкафов раскладки (только при подписи «Шкафов» в C21). Формула-оценка
  заменяется числом, от `D21` считает `D45`; на защищённом листе —
  предупреждение. В примере формула давала 2 шкафа, раскладка — 3.
- Номер в окне ошибки: «Ошибка конфигуратора (код N): …», где N — из таблицы
  «Ошибки» README; сбой самого VBA/Excel — «ошибка VBA N».
- Ошибка 29: количество в строке столбца D (в том числе D26) больше
  `MAX_QTY` = 10000 — почти наверняка опечатка; сообщение называет строку и
  появляется до любых расчётов (раньше — Overflow, Out of memory или
  многочасовой прогон).
- `ТестРазбораЧисел` — самопроверка разбора чисел в самом Excel (`Alt+F11` →
  курсор внутри → `F5`): те же 36 векторов, что в `tools/parse-spec.py`.

### Изменено

- `D19` текстом («20 %») разбирается `ЧислоИзТекста` с предупреждением; раньше
  такой текст молча давал 0 % резерва.
- При ручном режиме вычислений макрос пересчитывает книгу перед чтением: `D26`
  и ячейки сигналов — формулы.

### Исправлено

- `D13=YES`: барьеры строки 52 при модуле TC с выходами AO (`AIO.3.12/6`) и без
  модулей 30–32 молча уезжали в шкаф «S», хотя при `D13=NO` садятся на эти
  выходы. Теперь это ошибка 19; у прежних случаев номера не изменились.
- `Example.xlsx`: у `AIO.2.xx/2` и `AIO.3.12` одна ширина (164 мм) во всех
  строках Service — раньше разделы AI и AO расходились (164 / 160 мм).
- README: таблица «Ошибки» обещала номера 38, 39 и 74, которых в коде нет.

### Проверки и инфраструктура

- `tools/check-all.py` — все шаги CI одной командой на любой ОС
  (`check-all.sh` — обёртка). Шаблон PR больше не предлагает
  `python3 tools/check-all.sh`, падавшую с `SyntaxError`.
- Вывод всех `tools/*.py` — UTF-8: на Windows в pipe/файл они падали с
  `UnicodeEncodeError` (в cp1252 — все пять).
- `tools/check-example.py`: `Example.xlsx` против README («Значения примера»)
  и против Service (наименования строк `defRows` с шириной, одна ширина на
  наименование) — stdlib, без openpyxl.
- `check-sync.py` дополнительно сверяет: шаги `check-all.py` ↔ CI, вывод
  инструментов в cp1252, константы `ИМЯ` = N из README, номера ошибок ↔
  таблица README, векторы `ТестРазбораЧисел` ↔ `parse-spec.py`, джоб `windows`.
- CI: джоб `windows` (`python tools/check-all.py`), Dependabot для actions,
  push-фильтр + `.gitattributes` и `*.xlsx`.
- `.gitattributes`: `*.cls` / `*.frm -text`, `*.frx binary`.
- README: порядок обновления модуля — сначала удалить старый `Module1`, иначе
  VBE создаст `Module11` и в `Alt+F8` окажутся два `СоздатьКонфигуратор`.
