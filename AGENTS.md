# AGENTS.md — с чего начать агенту

Конфигуратор раскладки модулей АРКС400: `Module1.bas` (Excel VBA) читает
листы «1» и «Service», раскладывает железо шкафов по DIN-рейкам и рисует
схему на листе «1 расположение». Язык репозитория — русский: код, сообщения,
документация, коммиты.

## Порядок чтения

1. `README.md` — контракт листов, алгоритм, ошибки. Начни с карты «С нуля»
   в начале; дальше читай точечно, разделами задачи, не целиком.
2. Задача про укладку → `tools/plan-spec.py`; про разбор чисел →
   `tools/parse-spec.py`. Это исполняемые зеркала алгоритма (канон
   поведения), а не тесты VBA.
3. `Module1.bas` — только нужные процедуры (карта процедур — в README,
   `grep -n "^Private Sub" после iconv` даст индекс), не файл целиком.

## Ловушки

* `Module1.bas` — Windows-1251 + CRLF. `grep`/`cat` дадут кашу вместо имён;
  читать: `iconv -f cp1251 -t utf-8 Module1.bas`. Править — только с
  сохранением cp1251 + CRLF (побайтовый патч либо экспорт/импорт через
  VBE); чистоту кодировки и окончаний строк проверяет `tools/vba-lint.py`
  (E01/E02). UTF-8-копию файла рядом не создавать — это молчаливое
  дублирование, которое обязательно разойдётся с оригиналом.
* `Example.xlsm` — бинарник, не открывать и не править вслепую: его
  значения и лист Service сверяет `tools/check-example.py`.
* Правило зеркал: меняешь `Module1.bas` — тем же коммитом обнови
  `tools/*-spec.py` и `README.md`; иначе `tools/check-sync.py` упадёт.

## Перед push

    python3 tools/check-all.py --quiet

Те же шесть шагов, что в CI; полный вывод — без `--quiet`. Локально можно
включить хук: `git config core.hooksPath .githooks`. CI падает только на
ошибках `E*` линтера, но предупреждения `W*` держим нулём.

| Разбор чисел из текста | `ЧислоИзТекста`, `ИзвлечьЧисло`, `ТестРазбораЧисел` + `tools/parse-spec.py` + README «Разбор чисел» |

| Новый инструмент в `tools/` | сам инструмент + `STEPS` в `tools/check-all.py` + шаг CI + раздел «Проверки» README + вывод в UTF-8 последними строками |
| CI, actions, хуки | `.github/workflows/vba-lint.yml`, `.githooks/pre-commit` |
| Пример книги | `Example.xlsm` правится в Excel + «Значения примера» в README (сверит `check-example.py`) |
